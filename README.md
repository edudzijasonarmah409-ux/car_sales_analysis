# car_sales_analysis
Power BI dashboard analyzing 157 car sales records — cleaned messy pricing/date data, built DAX measures (CALCULATE, SUMMARIZE, FILTER), and visualized manufacturer sales, pricing, and vehicle type trends. Includes documented reasoning for chart choices and honest notes on what I'd improve


Car Sales Dashboard — Power BI

Analysis of 157 car sales records: manufacturer sales, pricing, and vehicle type trends, built in Power BI with DAX.

The things I did:
Cleaned pricing data (text-to-decimal conversion) and fixed inconsistent date sorting,
Investigated 36 missing resale values —ignored launch date and vehicle type as causes, found mild manufacturer clustering and left null values as true nulls
Built DAX measures  with CALCULATE, FILTER, and SUMMARIZE,
Visualized sales concentration, pricing trends, and vehicle type distribution across 6 panels

Analysis I Made:
Ford is responsible for 24% of the volume of sales that makes the market is highly concentrated in one manufacturer, driven by accessible pricing rather than premium positioning.

Tools I Used:
Power BI Desktop · Power Query · DAX

What I'd Improve
Switch one chart from Sum to Average pricing for a more accurate read on manufacturer price tier
Replace a dual-axis line chart with a bar/scatter to avoid implying a false trend across categories
